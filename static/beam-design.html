01 / เลือกเหล็กหน้าตัดคาน

จากแรงดัด สู่ชุดเหล็กที่ตรวจสอบได้

คานสี่เหลี่ยม · เหล็กดึงชั้นเดียว · เปรียบเทียบชุดเหล็กที่ผ่านการตรวจเฉพาะหน้าตัด

รุ่นทดลอง — รับ Mu ประลัยที่ผู้ใช้ตรวจแล้ว ยังไม่ดึงแรงจากโมเดล 3 มิติอัตโนมัติ และยังไม่ตรวจผ่านคานทั้งตัวหรืออาคาร

ข้อมูลออกแบบ

รองรับแรงดัดล้วน: N, T และโมเมนต์แกนอ่อนต้องกรอก 0 เมื่อยืนยันว่าไม่มีจริง ค่าที่เว้นว่างไม่ใช่ศูนย์ · cover วัดถึงผิวนอกปลอก · ปลอกใช้หาระยะ d เท่านั้น

เบอร์เหล็ก DB ที่ให้เปรียบเทียบ (mm)

เลือกจาก 2–12 เส้นในชั้นเดียว หน้าตัดคงที่ ไม่ลดเหล็กต่ำกว่าขั้นต่ำด้วยข้อยกเว้น 9.6.1.3

02 / ผลและรายการคำนวณ

กรอกข้อมูลเพื่อให้โปรแกรมเปรียบเทียบ
จำนวนเส้น เบอร์เหล็ก กำลังดัด และระยะเรียง

เป้าหมายรายงานตามตัวอย่างที่ให้มา

ผังระบุ B / S / C / F → โหลดและชุดน้ำหนัก → กราฟแรง → เลือกเหล็ก → ตรวจเกณฑ์ → รูปหน้าตัดและรายการคำนวณ โดยผูกผลกับรุ่นโมเดล

คาน

เริ่มแล้ว: เลือกเหล็กดึงจาก Mu
ยังขาด: เฉือน บิด ฝัง/ทาบ และการโก่ง

พื้น

ยังไม่ออกแบบเหล็ก
ต้องได้โมเมนต์ตามระบบพื้นก่อน

เสา

ยังไม่ออกแบบเหล็ก
ต้องตรวจ P–Mx–My และความชะลูด

ต้องแยกแรงใช้งาน/ประลัยและตรวจดิน
