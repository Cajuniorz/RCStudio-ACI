01 / สร้างโมเดล
🏛️ สร้างอาคารครบองค์ (หลังคา + พื้น + บันได + ฐานราก)

สร้างครบ: อะเส (AS) · ดั้ง (DANG) · จันทันยื่นชายคาเป็นเชิงชาย (RAF) · ตะเฆ่สัน (HIP) · อกไก่ (OK) · แป (P) · บันได (ST) · พื้นสองทาง/ทางเดียว · ฐานรากเสาเข็ม

สร้างอาคารโรงงาน + โครงถักเหล็ก (Truss)

เสา คสล. + โครงหลังคาเหล็กถัก + แป + คานรัดหัวเสา + คานคอดิน พร้อมแรงกระทำและจุดรองรับ

วัสดุและน้ำหนักตัวเอง

ค่าวัสดุเริ่มต้นเป็นตัวอย่าง ต้องตรวจค่าของโครงการ · ใช้หน้าตัดเต็ม · E ไม่ใช่กำลังอัด f′c

เพิ่มโหนด
เชื่อมคาน / เสา / หลังคา

หลังคาเหล็กต้องกรอก A / Iy / Iz / J ในตารางหลังคา ตามข้อมูลหน้าตัดจริง

เพิ่มองค์ประกอบอาคาร

กรอกโหนดขอบพื้นเรียงรอบรูป และโหนดที่ฐานรากรองรับ โดยคั่นด้วยจุลภาค

📐 กริดอาคาร + โครงชั้น (1–2–3 / A–B–C)

สร้างชื่อกริด 1,2,3… และ A,B,C… พร้อมโหนดที่จุดตัด คานที่สร้างใช้หน้าตัด b/h ปัจจุบัน · สร้างเฉพาะชั้น Y ที่ระบุ ไม่สร้างเสาหรือฐานราก · Undo ได้
