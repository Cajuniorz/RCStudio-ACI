# RCStudio 0.2 — โมเดลโครงสร้าง 3 มิติและหน่วยเมตริกไทย

สถานะ **PARTIAL** สำหรับโปรแกรมออกแบบอาคารครบระบบ รุ่นนี้เพิ่มการกรอกพื้น คาน เสา ฐานราก และโครงหลังคา พร้อมหน่วย m / cm / kgf / tf / ksc มีการวิเคราะห์โครงข้อแข็งและถ่ายโหลดพื้นทางเดียวตามขอบเขตด้านล่าง ยังไม่มีการออกแบบเหล็กเสริมหรือตรวจผ่านตามมาตรฐานก่อสร้าง

## เปิดใช้งาน

1. ดับเบิลคลิก `Start-RCStudio.bat` เพื่อเปิด http://127.0.0.1:8765
2. เปิดไฟล์ `examples/full-building-v02.rcstudio` เพื่อทดลองอาคารพร้อมพื้น ฐานราก และหลังคา ตัวอย่างเป็นข้อมูลศึกษา ไม่ใช่ขนาดที่แนะนำสำหรับก่อสร้าง
3. เลือกหน่วยด้านซ้าย แล้วแก้ตารางแต่ละประเภท ค่ากรอกยืนยันเมื่อออกจากช่อง
4. ตรวจแท็บ **สถานะ / ที่มาโหลด** ก่อนกดวิเคราะห์ ข้อมูลที่ยังไม่รองรับการวิเคราะห์จะบล็อกทั้งโมเดล เพื่อไม่ให้ส่วนของอาคารหายไปจากผลโดยไม่แจ้ง
5. **บันทึกโมเดล** สร้างไฟล์ใหม่ใน `projects` ทุกครั้ง **เปิดไฟล์** รองรับ `.rcstudio` รุ่นเดิม และ **ส่งออกผล** แนบโมเดลต้นทางพร้อมผลและ hash
6. เมื่อเลิกใช้งาน server ให้ดับเบิลคลิก `Stop-RCStudio.bat`

ทำงานในเครื่อง ไม่ต้องสมัครสมาชิกหรือใช้อินเทอร์เน็ต แต่ยังไม่ใช่ชุดติดตั้ง standalone: launcher ใช้ Python/PyNite เดิมที่ `H:\structure anlysis\.verification-tools\pynite-3.0.0\Scripts\python.exe` หากย้าย runtime ต้องแก้การตั้งค่า โค้ดโปรแกรมเดิมไม่ได้ถูกแก้

## หน่วย

| รายการ | เมตริกไทย | SI |
|---|---|---|
| พิกัด / ระยะอาคาร | m | m |
| หน้าตัด / ความหนา | cm | mm |
| แรง / โมเมนต์ | kgf หรือ tf / kgf·m หรือ tf·m | kN / kN·m |
| โหลดกระจาย / โหลดพื้นที่ | kgf/m / kgf/m² | kN/m / kN/m² |
| E | ksc | MPa |
| หน่วยน้ำหนักวัสดุ | kgf/m³ | kN/m³ |
| A / I / J | cm² / cm⁴ | mm² / mm⁴ |
| การเคลื่อนที่โหนด | mm | mm |

ข้อมูลและผล JSON ภายในคงหน่วยมาตรฐาน m–kN–MPa การสลับหน้าจอไม่เปลี่ยนค่าจริง 1 kgf = 0.00980665 kN, 1 tf = 9.80665 kN และ 1 ksc = 0.0980665 MPa โดย kgf เป็นหน่วยแรง ไม่ใช่มวล [อ้างอิง NIST](https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors/nist-guide-si-appendix-b9)

E คือโมดูลัสยืดหยุ่น ไม่ใช่กำลังอัดคอนกรีต f′c วัสดุคอนกรีตและเหล็กมี E, ν และหน่วยน้ำหนักแยกกัน ค่าเริ่มต้นเป็นค่าตัวอย่างที่ผู้ใช้ต้องตรวจ

## ประเภทและขอบเขต

| องค์ประกอบ | ประเภทที่กรอกและบันทึกได้ | วิเคราะห์ในรุ่นนี้ |
|---|---|---|
| พื้น | ทางเดียว สองทาง สำเร็จรูป ไร้คาน ribbed waffle post-tension steel deck และกำหนดเอง | ถ่ายแรงพื้นทางเดียวสี่เหลี่ยมแนวราบไปคานตรงข้ามสองด้าน ไม่มี plate FEM / diaphragm / ออกแบบพื้น |
| คาน / เสา | คอนกรีตสี่เหลี่ยม หรือหน้าตัดเหล็กกรอก A/Iy/Iz/J | โครงข้อแข็ง 3 มิติ เชิงเส้น อันดับหนึ่ง จุดต่อ rigid |
| ฐานราก | ฐานเดี่ยว ฐานร่วม ฐานแถบ ฐานแพ ฐานหัวเสาเข็ม เสาเข็ม และกำหนดเอง | บันทึกข้อมูลและเชื่อมกับโหนดรองรับที่ผู้ใช้ยึดไว้ ต้องเลือก ideal support เอง ยังไม่วิเคราะห์ดิน/เสาเข็ม/กำลังฐาน |
| โครงหลังคา | จั่ว ปั้นหยา เพิงแหงน แบน truss spaceframe โค้ง และกำหนดเอง | สมาชิกเส้นตรงที่ต่อเองเป็น frame; truss/spaceframe บล็อกการวิเคราะห์จนกว่าจะมีตัวแก้ที่รองรับ |

ตัวเลือกประเภทใช้จัดข้อมูล ไม่ใช่ตัวสร้างรูปทรงอัตโนมัติหรือยืนยันว่าออกแบบได้ทุกรูปแบบ หลังคาโค้งต้องจำลองด้วยสมาชิกเส้นตรงเอง ฐานรากแสดงเป็นกล่องเชิงสัญลักษณ์ ยังไม่มีการวางกลุ่มเสาเข็มจริง

## วิธีกรอกและสมมติฐาน

- แกน X/Z เป็นระนาบพื้น Y เป็นความสูง ใช้โหนดร่วมเพื่อเชื่อมสมาชิก เส้นตัดกันในภาพไม่ได้เชื่อมอัตโนมัติ
- เครื่องหมาย DX/DY/DZ ยึดการเลื่อน RX/RY/RZ ยึดการหมุน ฐานรากไม่สร้าง restraint ให้อัตโนมัติ
- คอนกรีตสี่เหลี่ยมใช้ b ตาม local z และ h ตาม local y หมุนหน้าตัดรอบ local x ได้ เหล็กใช้ A/Iy/Iz/J ที่กรอกโดยตรง ต้องได้จากหน้าตัดจริง ค่าตัวอย่างไม่ได้แทนหน้าตัดที่ผ่านการออกแบบ
- พื้นกรอกโหนดขอบตามลำดับ ใช้เครื่องหมายจุลภาคคั่น การถ่ายแรงรองรับเฉพาะ 4 มุมสี่เหลี่ยมแนวราบและคานสองตัวที่เป็นขอบตรงข้ามเต็มด้าน ไม่รับช่องเปิดหรือพื้นทับซ้อน
- โหมดถ่ายแรงใช้ได้กับพื้นทางเดียว สำเร็จรูป steel deck หรือกำหนดเอง โดยต้องเป็นระบบทางเดียวตามเงื่อนไขข้างต้น พื้นทางเดียวตันเลือกคำนวณน้ำหนักจากความหนาได้ ระบบอื่นต้องกรอกน้ำหนักตัวเองต่อพื้นที่โดยตรง
- โหลดพื้นแยก D = น้ำหนักตัวเอง + dead และ L = live ถ่ายไปคานแต่ละด้านด้วย q = p × พื้นที่ / (2 × ความยาวคาน) ตรวจสมดุลแรงและโมเมนต์ และเก็บต้นทางใน `coverage.floorLoadTransfers`
- โหลดพื้นบวกกับโหลดคานที่กรอกเอง ต้องระวังป้อนซ้ำ สวิตช์น้ำหนักสมาชิกครอบคลุมคาน เสา และหลังคา พื้นมีการคิดน้ำหนักแยก น้ำหนักฐานรากไม่รวมในตัวแก้โครงสร้างส่วนบน
- โหลดที่กรอกใช้แกน GLOBAL ค่าลบ FY/qY คือแรงลง ลูกศรและความหนาเส้นเป็นสัญลักษณ์
- ข้อมูลดิน/เสาเข็มที่ไม่ทราบเว้นว่างได้ ไม่แทนด้วยศูนย์ ค่า qa และกำลังเสาเข็มยังไม่ถูกใช้ตรวจออกแบบ
- D/L/W และชุดตัวคูณโหลดกำหนดเอง ตัวอย่าง Service = D + L เพื่อทดสอบ ไม่ใช่ชุดตามมาตรฐานใด

## อ่านผลและไฟล์

ผลโหนดใช้แกน GLOBAL ผลสมาชิกใช้แกน LOCAL ตาม PyNite พร้อมเวกเตอร์อ้างอิง กราฟเก็บ 41 จุดต่อสมาชิก ไม่ใช่การหาค่าสูงสุดระหว่างทุกจุด เส้นโก่ง ×100 เชื่อมตำแหน่งโหนดที่เคลื่อน ไม่ใช่โค้งโก่งตลอดสมาชิก ตรวจสมดุลครบ 6 องค์ประกอบและตรวจ stiffness ของ DOF อิสระก่อนยอมรับผล

การแก้ข้อมูลจะล้างผลเก่า การเปลี่ยนหน่วยแสดงผลอย่างเดียวคงผลเดิม Undo เก็บ 40 ครั้งในรอบเปิดหน้า บันทึก draft ที่ยังไม่สมบูรณ์ได้ แต่ต้องผ่าน validation ก่อนวิเคราะห์

schema v2 เก็บ `canonicalUnits: m-kN-MPa` และ `displayUnits` ไฟล์ v1 แปลงเข้ารุ่นใหม่โดยคงค่าจริง สำรอง autosave v1 ใน localStorage ก่อนเปลี่ยนรุ่น แนะนำบันทึกไฟล์แทนการพึ่ง autosave อย่างเดียว
